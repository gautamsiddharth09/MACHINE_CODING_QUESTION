# 🌗 Theme Mode

A simple yet effective React project that allows users to switch between **Light** and **Dark** themes. This challenge demonstrates how to manage global state using **React Context API** and dynamically apply styles across the application.

## 🚀 Features

- 🌞 Light Theme
- 🌙 Dark Theme
- 🔄 Instant Theme Switching
- 🌍 Global Theme Management with Context API
- 💾 Theme Persistence (Optional - Local Storage)
- 📱 Responsive Design

## 🛠️ Tech Stack

- React.js
- Context API
- CSS3

## 📚 Concepts Covered

- React Context API
- Global State Management
- Dynamic Styling
- Conditional Rendering
- Component Reusability
- Theme Persistence (Optional)

## 🎯 Learning Outcomes

- Create and provide a global context.
- Consume context using `useContext`.
- Dynamically update UI styles based on application state.
- Improve user experience with theme persistence.
- Build scalable and maintainable React applications.
